ISRO Smart India Hackathon 2026 · Problem Statement SIH26169
Coarse alignment of mobile Free Space Optical Communication terminals using real-time AI.

SIH26169 ISRO FSOC TF.js COCO-SSD Kalman Filter PID Control WebRTC

🎯 Problem Statement

Mobile FSOC terminals need to rapidly align their optical axis to establish high-bandwidth laser links. Manual coarse alignment is slow and error-prone. This system uses AI-based computer vision to automate the initial acquisition phase.

💡 Our Solution

  • Live webcam input with TF.js COCO-SSD universal object detection
  • Sub-pixel beacon localization via optical moment analysis
  • 4-state Kalman filter for trajectory prediction & smoothing
  • PID controller generating virtual gimbal commands
  • 5-state FSM: IDLE → ACQUIRING → TRACKING → LOCKED → LOST

🏗️ System Architecture

  • WebRTC MediaDevices API for zero-latency live camera capture
  • COCO-SSD MobileNet-v2 — detects 80+ object classes in real-time
  • NMS (IoU-based) + EMA temporal smoothing to eliminate jitter
  • Chart.js for live telemetry visualization
  • SQLite persistence layer via Python REST backend (optional)

⚙️ Technology Stack

TensorFlow.js COCO-SSD v2 WebRTC Chart.js Canvas API Kalman Filter PID Controller Python Flask SQLite GitHub Pages
