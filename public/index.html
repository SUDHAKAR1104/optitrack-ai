Official Problem Statement: Development of an AI-Based Virtual Camera Tracking System for Coarse Alignment of Mobile Free Space Optical Communication (FSOC) Terminals.

1. Multi-Class Universal Detection Architecture

OptiTrack AI bridges classical intensity moments with edge deep-learning neural networks. The system recognizes 80 distinct classes of entities—including humans, animals, electronics, and optical beacons. Once an entity is selected or auto-acquired, the closed-loop tracking pipeline estimates kinematic motion dynamics with the 4-State Kalman Filter and drives the Virtual Camera Gimbal to maintain continuous boresight alignment.

2. Hand / Obstacle Occlusion Defense

Judges can verify algorithmic resilience by temporarily covering the tracked person, animal, or object with a hand or obstacle. The 5-State Finite State Machine enters COASTING mode, and the Kalman Filter maintains dead-reckoning along the velocity vector $[v_x, v_y]$. When the obstruction is removed, the target is instantly re-acquired within < 100 ms without needing a blind spatial search.

z_k = H · x_k + v_k,   where H = [[1, 0, 0, 0], [0, 1, 0, 0]]
