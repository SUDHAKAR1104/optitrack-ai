Automated coarse alignment of mobile Free Space Optical Communication terminals using real-time AI.

SIH26169 ISRO FSOC TensorFlow.js COCO-SSD v2 Kalman Filter PID Control WebRTC Canvas API

🎯 Problem Statement

Mobile FSOC terminals need rapid optical axis alignment to establish high-bandwidth laser links. Manual coarse alignment is slow and error-prone in field conditions. This system uses AI computer vision to fully automate the acquisition phase, reducing lock time from minutes to under 500 ms.

💡 Innovation

  • Live laptop webcam — no pre-recorded datasets
  • Universal AI detection: humans, animals, vehicles, 80+ object classes
  • Sub-pixel beacon localization via optical moment analysis
  • 4-state Kalman filter for trajectory prediction & smoothing
  • 5-state FSM: IDLE → ACQUIRING → TRACKING → LOCKED → LOST
  • PID closed-loop virtual gimbal controller

⚙️ System Pipeline

  • WebRTC MediaDevices API — zero-latency camera capture
  • COCO-SSD MobileNet-v2 — 80+ classes @ 60 FPS
  • NMS (IoU-based) + EMA temporal smoothing
  • Click-to-lock: select any detected entity as primary target
  • Color pipette beacon sampling on empty-space click
  • 8-scenario synthetic benchmark suite for ISRO evaluation

📊 Performance Claims

  • Boresight error < 10 px (ISRO coarse spec ✓)
  • Lock rate > 90% across all 8 benchmark scenarios
  • Detection latency < 50 ms on modern hardware
  • 60 FPS real-time operation
  • Lock acquisition < 500 ms typical
  • Kalman filter reduces RMS error by ~40%

🏗️ Technology Stack

TensorFlow.js 4.11 COCO-SSD MobileNetV2 WebRTC getUserMedia HTML5 Canvas API 4-State Kalman Filter PID Controller 5-State FSM IoU-based NMS EMA Temporal Smoothing Python Flask (optional) SQLite Persistence GitHub Pages CI/CD
Deployment Note

This is a fully static web app — zero install, zero build step. Works on GitHub Pages with HTTPS, which automatically enables WebRTC camera access. The optional Python server adds CSV telemetry persistence when run locally via python server.py.
